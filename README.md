## サービス概要

「言語化ジム」は、相手に合わせて分かりやすく説明する力を鍛えるトレーニングアプリです。

ユーザーは **「テーマ」** **「相手」**を設定し、相手に合わせた説明を入力します。

入力した説明をAIが分析し、説明の分かりやすさや構成、専門用語の使い方などについてフィードバックを行います。

自分の説明を客観的に振り返り、改善を繰り返すことで、相手に伝わる説明力を身につけることを目的としています。

## 開発背景

前職でお客様に商品の説明をしている時に、同じ内容で説明をしていても、伝わっている時と伝わっていない時があると感じることがありました。

その経験から、「誰」に説明するかで難易度が大きく変わることに気づきました。

実際に、お客様の年齢や知識、関心のあるポイントなどによって、説明する順番や言葉の選び方を変えることで、反応が良くなったり、質問が減ったりすることがありました。

その後、プログラミングを学習する中でも、同じような難しさを感じました。

自分では理解しているつもりでも、いざ人に説明しようとすると、

* どの順番で説明すればよいか分からない
* 専門用語を使いすぎてしまう
* 自分の説明が相手に伝わっているか分からない

といったことがありました。

そこで、**「相手に合わせて分かりやすく説明する力」を練習できる環境があれば、言語化力を高められるのではないか**と考え、「言語化ジム」を開発しました。
